# 최근 수정 및 배포 기록

Codex와 Claude가 함께 사용하는 인계 문서다. 최신 항목을 맨 위에 추가한다.
작업 시작 시 이 문서와 `git status`를 확인하고, 완료 시 실제 검증 결과와 배포 상태를 갱신한다.

## 2026-10-26 — 저장된 프로젝트 선택 삭제·전체 삭제

- 요청: 이 컴퓨터의 프로젝트를 여러 개 선택해서 삭제하거나 한 번에 모두 삭제할 수 있게 한다.
- 변경: `ProjectPicker.vue`에 프로젝트별 체크박스, 전체 선택, 선택 삭제(개수), 프로젝트 전체 삭제를 추가했다.
- 확인: `WelcomeView.vue`에서 삭제 대상 이름과 개수를 먼저 표시한다. 취소하면 삭제하지 않는다.
- 보호: 기존 `withTabLock`과 `deleteProject`를 사용한다. 다른 탭에서 사용 중이거나 삭제에 실패한 항목은 오류를 알리고, 나머지 항목을 계속 처리한 뒤 목록을 갱신한다.
- 범위: 현재 브라우저·사이트의 IndexedDB 프로젝트만 삭제하며 내려받은 `.mlpx` 파일은 삭제하지 않는다. 기존 개별 삭제도 유지한다.
- 언어: 한국어와 영어 문구를 함께 추가했다.
- 검증: `npm run ci` 전체 통과(165개 테스트 파일, 3,314개 통과·2개 제외). 백본 검사, ESLint·Prettier, 타입 검사, Python sklearn 픽스처 대조, 프로덕션 빌드를 모두 통과했다. 로컬 CI는 샌드박스의 Python 캐시 권한 문제를 피하기 위해 작업 폴더의 `.cache/uv`를 사용해 실행했다.
- 배포: 사용자 승인으로 공개 사이트 배포를 완료했다. 결과는 아래와 같다.
- 협업: `CLAUDE.md`에서 이 문서를 안내하며 이후 작업도 변경 이유·검증·배포 결과를 계속 기록한다.
