# 최근 수정 및 배포 기록

Codex와 Claude가 함께 사용하는 인계 문서다. 최신 항목을 맨 위에 추가한다.
작업 시작 시 이 문서와 `git status`를 확인하고, 완료 시 실제 검증 결과와 배포 상태를 갱신한다.

## 2026-10-26 — 결과 탭에 실험 설정 표시

- 요청: 수행평가 결과물을 평가할 때 **어떤 특성·타깃으로, 어떤 전처리를 거쳐** 모델을
  만들었는지 결과 탭에서 확인할 수 있어야 한다.
- 문제: 지금 결과 탭은 **직전 실험 대비 바뀐 것**만 보여준다. 첫 실험이거나 설정을
  안 바꾸고 다시 학습하면 아무것도 안 뜨고, **절대 설정을 읽을 자리가 없다.**
  교사는 `.mlpx` 하나로 과정을 평가해야 하는데(CLAUDE.md §1.3) 그 과정이 안 보인다.
- 변경: `ml/changes.ts`에 `experimentSettings()`를 더해 실험 하나의 설정을 **차이 보기와
  같은 등록부(`LABELS`)·같은 값 서술(`Describe`)**로 낸다. 어휘를 두 벌로 만들지 않는다.
- 화면: `results/SettingList.vue`를 `ExperimentDetail.vue`의 접이식 블록으로 넣는다.
  특성처럼 목록인 값은 눌러서 이름을 펼쳐 본다(차이 보기와 같은 규칙).
- 범위: 하이퍼파라미터는 넣지 않는다 — 이미 모델마다 `ParameterPanel`이 보여준다.
- 정직성: **학습이 무시하는 값은 설정으로 말하지 않는다.** 회귀의 `stratify`는 파일에
  남아 있지만 학습이 무시하므로(`ml/selection.ts` — 유형을 바꿀 때 값을 안 내리는 것이
  결정) 그대로 보이면 평가자가 *"층화를 썼다"*고 읽는다. 군집화의 분할 설정도 같다.
  판정은 학습이 쓰는 `stratifyApplies`·`splitsData`를 그대로 부른다 — 두 벌로 만들지 않는다.
- 검증: `npm run ci` 전체 통과(165개 테스트 파일, 3,325개 통과·2개 제외). `changes.spec.ts`에
  12개를 더했다 — 첫 실험에도 나오는지, 차이 보기와 같은 어휘인지, 종류에 없는 설정이
  빠지는지, 학습이 무시하는 값이 빠지는지.
- 화면 확인: 로컬 미리보기에서 청주 대기질 CSV로 회귀 실험을 돌려 10줄(기계학습 유형·타깃·
  특성 5개·결측치·이상치·스케일링·인코딩·분할 방법·테스트 비율·난수 씨앗)이 뜨는 것과,
  `목록 보기`가 고른 열 다섯을 정확히 펼치는 것, 회귀에서 `범주 비율 유지` 줄이 빠지는 것을
  확인했다.
- 진행 중. 배포 결과는 아래에 갱신한다.

## 2026-10-26 — 저장된 프로젝트 선택 삭제·전체 삭제

- 요청: 이 컴퓨터의 프로젝트를 여러 개 선택해서 삭제하거나 한 번에 모두 삭제할 수 있게 한다.
- 변경: `ProjectPicker.vue`에 프로젝트별 체크박스, 전체 선택, 선택 삭제(개수), 프로젝트 전체 삭제를 추가했다.
- 확인: `WelcomeView.vue`에서 삭제 대상 이름과 개수를 먼저 표시한다. 취소하면 삭제하지 않는다.
- 보호: 기존 `withTabLock`과 `deleteProject`를 사용한다. 다른 탭에서 사용 중이거나 삭제에 실패한 항목은 오류를 알리고, 나머지 항목을 계속 처리한 뒤 목록을 갱신한다.
- 범위: 현재 브라우저·사이트의 IndexedDB 프로젝트만 삭제하며 내려받은 `.mlpx` 파일은 삭제하지 않는다. 기존 개별 삭제도 유지한다.
- 언어: 한국어와 영어 문구를 함께 추가했다.
- 검증: `npm run ci` 전체 통과(165개 테스트 파일, 3,314개 통과·2개 제외). 백본 검사, ESLint·Prettier, 타입 검사, Python sklearn 픽스처 대조, 프로덕션 빌드를 모두 통과했다. 로컬 CI는 샌드박스의 Python 캐시 권한 문제를 피하기 위해 작업 폴더의 `.cache/uv`를 사용해 실행했다.
- 배포: 사용자 승인으로 공개 사이트 배포를 완료했다. 결과는 아래와 같다.
- 협업: `CLAUDE.md`에서 이 문서를 안내하며 이후 작업도 변경 이유·검증·배포 결과를 계속 기록한다.
